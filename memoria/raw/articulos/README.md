# Carpeta de Artículos (`raw/articulos/`)

Coloca aquí recortes web, publicaciones de blogs, newsletters y artículos de prensa.
Puedes utilizar la extensión de navegador **Obsidian Web Clipper** para exportar directamente artículos en Markdown hacia esta carpeta.

Una vez colocado un artículo, pídele al agente que realice su ingesta en la wiki.
