# React

## Definición
**React** es una biblioteca de JavaScript de código abierto desarrollada por Meta para construir interfaces de usuario basadas en componentes reutilizables y reactivos.

## Relevancia en Festejia
- **Versión**: React 19.
- Implementa hooks personalizados como `useVisibleInterval` para pausar animaciones pesadas y cronómetros cuando están fuera de la pantalla del dispositivo móvil (véase [[optimizacion-rendimiento-movil]]).
- Soporta la reactividad del [[sistema-rsvp-inteligente]] y el simulador de teléfono interactivo.
